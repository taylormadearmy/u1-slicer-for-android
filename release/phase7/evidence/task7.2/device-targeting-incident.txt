Outcome
The unauthorized install attempt violated the explicit target boundary. The package manager rejected the APK before installation because the APK had no matching ABI. Gradle reported installDebug FAILED and BUILD FAILED. This output proves that the APK was not installed on 127.0.0.1:15556 by this attempt.
