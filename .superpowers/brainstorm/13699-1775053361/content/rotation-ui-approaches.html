Model Rotation UI — Where should it live?

The rotation controls need to fit alongside the existing Scale & Copies card on the Prepare screen. Three approaches:

⇄ Scale & Copies
Uniform ●—————○ 100%
Copies: 1 ●——○
↻ Rotation
X ○————● 0°
Y ○————● 0°
Z ○————● 0°
[ Reset to 0° ]

A — Separate Card

Rotation gets its own card below Scale & Copies, matching the existing card pattern exactly. Three sliders (X/Y/Z), 0–360°. Clean and consistent with ScaleSection.

✓ Consistent with existing UI pattern
✓ Plenty of room for 3 sliders
✗ Adds height to the Prepare sheet
⇄ Scale & Copies & Rotation
[ Scale ] [ Rotation ] ← tabs
X ○————● 0°
Y ○————● 0°
Z ○————● 0°

B — Tabbed inside Scale card

Rotation becomes a second tab inside the existing Scale & Copies card. Keeps the sheet compact — you only see one set of sliders at a time.

✓ No extra card height
✓ Groups related transforms
✗ Hides rotation behind a tab (less discoverable)
✗ Modifies existing ScaleSection component
⇄ Scale & Copies
Scale ●————○ 100% Copies ●—○ 1
Rotation X Y Z °

C — Compact row in Scale card

Rotation added as a compact inline row at the bottom of the Scale card — three small numeric fields (X/Y/Z degrees). No sliders. Smallest footprint.

✓ Minimal added height
✓ Precise degree entry
✗ Numeric input less friendly for discovery/exploration
✗ Mixes two concerns in one card
