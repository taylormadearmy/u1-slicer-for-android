# v5.0.0 release notes

Version 5.0.0 adds profile-driven slicing and upload for supported rectangular-bed FDM printers while keeping the Snapmaker U1 as the default. The pinned `taylormadearmy/OrcaSlicer` v2.2.4 source catalogue contains 326 models across 56 usable vendors. The wizard shows the eligible subset after its geometry, physical-slot, and firmware checks. You can also import an `.orca_printer` bundle.

The printer wizard resolves inherited Orca settings and validates the result before saving it. Each configured printer retains its profile and 1 to 4 physical slots. Cached profiles remain available offline. Generic printers can use Klipper or Marlin G-code with Moonraker, OctoPrint, or PrusaLink upload when the selected transport supports the operation.

Existing Bambu support remains a separate opt-in beta path. Version 5.0.0 does not add delta or circular beds, shared-extruder multi-material machines, SDCP or Duet transports, more than four physical extruders, or generalized ColorMix and Smart Paint mix encoding.
