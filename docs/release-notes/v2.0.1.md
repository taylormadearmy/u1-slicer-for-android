# v2.0.1 - Support/interface filament fixes and STL filament tuning

## What's changed for you

v2.0.1 is a focused follow-up to v2.0.0. It keeps the v2 file-filament model, but fixes the support/interface edge cases found during sanity testing and adds the missing STL-native material controls before slicing.

- **STL jobs can now tune filament material per slot before slicing.** This fixes the confusing v2.0.0 gap where 3MF file filaments could carry material types, but STL jobs had no good pre-slice way to set the type for otherwise-unused slots that are later selected for support or interface material.
- **Support and support-interface filaments now propagate correctly into slicing.** Selecting PETG support/interface on a PLA model now reaches the slicer config and exported G-code consistently instead of collapsing back to PLA in the preview/summary path.
- **Support/interface labels are clearer.** The UI now exposes support/interface options using the same file/slot-aware filament labels used by the rest of the v2 flow, including sparse and non-identity mappings.
- **Print/export G-code remapping is covered by the batch E2E harness.** The release sanity flow now exports print-ready G-code through the same Save/Share remap boundary and verifies no orphan `T4`-`T9` tool changes are left behind.

## Bug fixes

### Benchy STL support/interface filament mismatch

Reproduced with `3DBenchy.stl` and support/interface filament choices where the Prepare settings used PETG but the G-code preview summary could still show PLA or omit the intended support/interface filament. The fix carries per-slot `filament_type` through `SliceConfig`, JNI, and the native slicer configuration so STL support/interface choices are represented correctly.

### H2C / coloured Benchy support-interface regression guard

Added coverage for support/interface PETG scenarios on coloured Benchy/H2C-style multi-filament cases so the support/interface filament settings do not regress back to the model filament.

### Shashibo plate 5 and multi-plate batch coverage

The batch E2E harness now correctly waits for multi-plate readiness, selects the requested plate, waits for the latest loaded state after plate selection, and only then slices. Shashibo plate 5 passes the final batch run.
